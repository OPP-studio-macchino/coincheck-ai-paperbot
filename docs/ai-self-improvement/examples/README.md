# 合成データによる結果画面の例

[synthetic-demo-13000.html](synthetic-demo-13000.html) をブラウザで開くと、MVPの研究結果画面を確認できます。
同じ内容の機械可読データは [synthetic-demo-13000.json](synthetic-demo-13000.json) です。

これは**合成価格・固定応答**の機能検証です。実相場の成績、実残高、OpenAIモデルの提案結果ではありません。
2026-11-05にiMacの独立Docker projectで実行し、購入上限13,000円、初期仮想資金100,000円、6試行すべて不採用で終了しました。
最終評価期間は使用しておらず、Botへの反映も行っていません。

再現には同じソース、policy、seed 47、180日、6試行、13,000円の予算を使います。
ソース識別情報とPython 3.12.16での実行情報はJSONのmanifestに含まれます。
履歴に記録された価格・BTC数量・損益はすべてこの合成データから計算した仮想値です。
入力CSV、SQLite台帳、ホストのログ、秘密ファイルは公開例に含めていません。

実行方法は[運用手順](../OPERATIONS.md)、検証範囲は[検収書](../ACCEPTANCE_20261105.md)を参照してください。
